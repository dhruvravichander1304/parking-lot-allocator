Parking Lot Allocator

Memory management in an operating system, shown as cars and parking slots. Cars are processes, slots are memory blocks.

Side by side

What happened, step by step

Cars arrive and leave over time. When a car leaves, its space joins any free space next to it. Every strategy plays the same script, and each memory strip shows the state after that step.

A process uses pages in the order of its reference string. If the page it needs is not in a frame, that is a page fault and a resident page must be replaced. Each frame column below shows what is in memory after every reference.

A one-lane strip with a gate at each end. Write each car with < (leaves through the left gate) or > (leaves through the right gate). A car can only leave when no car stands between it and its gate. If two cars block each other, that is a deadlock and nothing moves.

Exact layout

Positions are counted from the left gate. Each car shows its exit gate and what it waits for.
